# Research Portfolio

Welcome to my research portfolio. This repository showcases selected analytical and research projects that demonstrate my experience working with data, applying statistical and computational methods, and investigating real-world social and urban issues.

The projects combine data preparation, exploratory data analysis, statistical modelling, and visualization to investigate research questions and communicate findings.

## Research Projects

### 1. Determining Which Households Need Social Assistance

**Folder:** [`social-assistance-classification/`](./social-assistance-classification/)

This project explores the use of classification techniques to identify households that may require social assistance, using data from Brazil's 2016 Urban Mobility Survey.

The analysis includes data cleaning, exploratory data analysis, correlation analysis, and the development of a Decision Tree classification model.

**Key areas:**
- Data cleaning and preprocessing
- Exploratory data analysis and visualization
- Classification modelling
- Decision Tree analysis and model evaluation

### 2. Spatial Analysis of Public Spaces and Socioeconomic Inequality in Toronto

**Folder:** [`toronto-public-space-spatial-analysis/`](./toronto-public-space-spatial-analysis/)

This project investigates the spatial distribution of public spaces in Toronto and their relationship with neighbourhood-level socioeconomic characteristics.

The analysis uses geographic data and spatial statistical techniques to explore spatial patterns, relationships, and potential inequalities in access to public spaces.

**Key areas:**
- Geographic data preparation and spatial analysis
- Exploratory spatial data analysis
- Spatial statistics and spatial modelling
- Geographic visualization

## Tools and Technologies

The projects in this portfolio use a range of analytical and computational tools, including:

- **Python:** Data manipulation, exploratory analysis, visualization, and machine learning.
- **R:** Statistical analysis, spatial analysis, modelling, and visualization.
- **Jupyter Notebook:** Interactive analysis and documentation.
- **R Markdown:** Reproducible analytical reports.
- **Statistical and Machine Learning Methods:** Classification, regression, and spatial statistical techniques.

*Specific tools and methods are documented in the README for each project.*
